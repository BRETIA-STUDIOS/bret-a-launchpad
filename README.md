# BRETÌA Launchpad

Create the first version of the official BRETÌA Web Studio website.

BRETÌA is a modern, independent and agile Italian web studio that creates professional websites and digital experiences for small and medium-sized businesses.

CORE MISSION:

“Professional digital presence should not be a luxury.”

BRETÌA exists to make professional digital presence accessible to small businesses through competitive and transparent pricing, without compromising quality, design or attention to detail.

Use this core idea throughout the website:

“Essere una piccola attività non significa dover avere una piccola presenza digitale.”

BRETÌA achieves competitive pricing through an agile structure, efficient production processes, technology and reusable systems.

Do NOT mention AI as part of the commercial positioning.

BRETÌA should feel premium, modern, technological, creative, confident, accessible and sophisticated.

Avoid any appearance of a cheap agency, generic template, cyberpunk website, gaming website, crypto website or excessive futuristic design.

==================================================

BRAND

==================================================

Brand name:

BRETÌA

Descriptor:

WEB STUDIO

BRETÌA has an official abstract interwoven symbol made from two rounded ribbon-like elements forming a continuous geometric mark.

Use this abstract symbol throughout the website.

Do NOT replace it with an animal or create a different logo.

Use the symbol as:

- main logo mark

- favicon

- decorative element

- animated logo

- recurring graphic signature

- footer signature

The future client-site signature must be:

“powered by [BRETÌA symbol]”

Keep this signature minimal.

==================================================

VISUAL STYLE

==================================================

Use a premium dark visual identity.

Primary background:

very dark navy / almost black

Secondary surfaces:

dark charcoal / slightly lighter navy

Primary text:

white / very light gray

Accent:

electric blue

Use electric blue carefully for:

- CTA buttons

- highlights

- active states

- subtle borders

- selected elements

- restrained gradients

Do not overuse blue.

Avoid excessive glow, excessive glassmorphism, excessive gradients and excessive neon.

Use generous negative space.

Use large editorial typography.

The website should feel like a high-end modern digital design studio.

==================================================

TYPOGRAPHY

==================================================

Use a modern, highly legible sans-serif font.

Create strong contrast between:

- large headlines

- supporting text

- small uppercase labels

- navigation

Use consistent typography tokens.

==================================================

ANIMATION

==================================================

Create the BRETÌA abstract symbol as an SVG/vector-style element when possible.

Create a refined one-time logo entrance animation:

1. Two symbol elements begin slightly separated.

2. They move smoothly toward each other.

3. They interweave.

4. They settle into the final symbol.

5. BRETÌA wordmark fades in.

6. WEB STUDIO appears subtly.

Duration:

approximately 1.2–1.5 seconds.

Do not loop the animation.

Use elegant easing.

Also add subtle scroll reveal animations and refined hover interactions.

Avoid excessive motion.

Respect prefers-reduced-motion.

==================================================

Create reusable components for:

- Header

- Logo

- Primary Button

- Secondary Button

- Service Card

Centralize colors, spacing, typography, border radius and transitions through reusable design tokens / CSS variables.

==================================================

RESPONSIVE DESIGN

==================================================

The entire website must be fully responsive.

Design intentionally for:

- mobile

- tablet

- laptop

- desktop

- large desktop

Check layouts around:

320px

375px

390px

430px

768px

1024px

1440px

Avoid horizontal overflow.

Make touch targets comfortable on mobile.

Do not simply shrink the desktop layout.

==================================================

ACCESSIBILITY & PERFORMANCE

==================================================

Use semantic HTML.

Include accessible navigation, focus states, form labels and sufficient contrast.

Prefer lightweight animation techniques using transform and opacity.

Avoid unnecessary dependencies.

Avoid unnecessary backend functionality.

Do not create authentication, databases, payments or complex backend systems.

This is currently a premium marketing website.
